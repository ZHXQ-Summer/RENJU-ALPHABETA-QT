# RENJU-ALPHABETA-QT

这是一个基于Qt框架开发的五子棋游戏，集成了Alpha-Beta剪枝算法实现的AI对手，支持人机对战，具备完整的游戏逻辑和交互界面。

## 功能特点

- **图形化界面**：使用Qt的QGraphicsScene和QGraphicsView绘制棋盘和棋子，界面简洁直观
- **人机对战**：玩家可选择黑棋或白棋，与AI进行对战，AI通过Alpha-Beta剪枝算法决策
- **游戏控制**：包含开始、重新开始、悔棋、保存、加载和退出等完整功能按钮
- **胜负判定**：自动检测横向、纵向、左上右下、左下右上四个方向的五子连珠情况
- **禁手规则**：实现长连、三三、四四等禁手判断，符合标准五子棋规则
- **平局检测**：当棋盘下满仍无胜负时，自动判定为平局

## 技术实现

### 界面渲染
- 使用Qt的QGraphicsScene作为绘图场景，QGraphicsView作为视图容器
- 棋盘由15x15的方格组成，通过QGraphicsRectItem绘制
- 棋子使用QGraphicsEllipseItem绘制，黑棋为黑色填充，白棋为白色填充

### AI算法核心
- 采用Alpha-Beta剪枝算法进行博弈树搜索，减少计算量
- 搜索深度可配置（代码中默认使用不同深度参数）
- 局面评估函数通过分析棋链组合（活三、冲四等）计算分数
- 初始落子时优先选择棋盘中心位置（7,7）

### 数据结构
- 使用16x16二维数组`chessboard`存储棋盘状态（1表示黑棋，-1表示白棋，0表示空）
- `node`结构体存储落子坐标和分数信息
- `step`数组记录落子历史，支持悔棋功能

### 关键函数说明
| 函数 | 功能描述 |
|------|----------|
| `winner_check` | 检查指定位置落子后是否形成五子连珠 |
| `a_b` | Alpha-Beta剪枝算法实现，搜索最佳落子位置 |
| `evaluate` | 评估当前局面分数，指导AI决策 |
| `Node_check` | 检查落子位置是否合法（非空、非禁手） |
| `longchain_check`/`threefour_check` | 禁手规则检查 |

## 代码结构

- `main.cpp`：程序入口，创建Qt应用和主窗口
- `widget.h`/`widget.cpp`：主窗口类，实现界面绘制、用户交互和核心游戏逻辑
  - 包含鼠标点击落子、胜负判定、游戏控制等功能
  - 实现Alpha-Beta剪枝算法和局面评估
- `bot.cpp`：AI决策模块，包含独立的算法实现（可能用于扩展或测试）

## 使用方法

1. 运行程序后，点击"游戏开始"按钮，选择黑棋或白棋
2. 轮到玩家回合时，用鼠标点击棋盘交叉点落子
3. AI会自动计算并落子，交替进行直到游戏结束
4. 游戏过程中可使用：
   - 重新开始：清空棋盘，重新开始游戏
   - 悔棋：撤销上一步操作
   - 保存/加载：保存当前游戏状态或加载之前的状态
5. 当一方形成五子连珠或出现平局时，游戏结束并提示结果

## 规则说明

- 遵循标准五子棋规则，先形成五子连珠者获胜
- 黑棋有禁手限制（长连、三三、四四），白棋无禁手
- 禁手位置点击时会提示"此处禁手"，无法落子

## 依赖环境

- Qt 5/6 框架
- C++ 编译器（支持C++11及以上标准）
- jsoncpp（用于AI模块的JSON解析，在bot.cpp中使用）
